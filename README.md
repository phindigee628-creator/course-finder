# Course Finder (Learning Project)

A sample quiz that helps a school leaver find a study area that fits them. It is **for guidance only** and is **not a real college or advice service**.

**Live site:** https://github.com/phindigee628-creator/course-finder/settings/pages

**Built with:** HTML, CSS and JavaScript

**What it does:**
- Asks 8 questions about interests and strengths.
- Scores every answer and ranks 6 study areas.
- Shows the best match with study options, jobs and next steps, plus the top 3 matches as percentage bars.
- Lets the user go back and change an answer, and share the result on WhatsApp.

**Skills shown:** JavaScript data and scoring, updating the page live, multi-screen design, accessibility (keyboard and screen readers) and responsive design.

**Make it yours:** all the questions, scores and results are in the data at the top of `script.js`.
